Notesコーナーへようこそ

ちょっと調べたこと、AIに調査してもらった結果、忘れたくないスニペットなどを気軽に書き残しておく場所です。

ブログはもう少しちゃんとした記事向けで、こちらはメモ書き程度のラフなものを想定しています。

コードブロックの例

コードスニペットはシンタックスハイライト付きで表示されます。

use strict;
use warnings;

sub greet {
    my ($name) = @_;
    return "Hello, $name!";
}

print greet("world"), "\n";

# ちょっとしたシェルのワンライナー
find . -name '*.md' | xargs wc -l

新しいノートの追加方法

notes/src/ 配下にMarkdownファイルを追加します。1行目がタイトルになります（# タイトル でもプレーンテキストでもOK）。追加したら以下を実行します。

perl regen-index.pl

ノート同士のリンク

1トピック1ファイルを基本に、[[ファイル名]]と書くと他のノートにリンクできます。例えば談合坂の地名由来のように書くと、そのノートのタイトルでリンクが張られます。表示テキストを変えたい場合は[[dangouzaka-yurai|地名の話]]のように|区切りで指定できます。

リンクされた側のノートには、どのノートからリンクされているかが自動で「🔗 リンクされているノート」として表示されます（バックリンク）。存在しないファイル名を指定するとビルド時に警告が出ます。
