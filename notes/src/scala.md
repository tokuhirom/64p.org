# Scala

スイス連邦工科大学ローザンヌ校(EPFL)のMartin Oderskyが設計し、2003年にリリースされたプログラミング言語。

## 特徴

- オブジェクト指向と関数型プログラミングの両パラダイムを自然に組み合わせられるマルチパラダイム言語
- JavaVirtual Machine(JVM)上で動作するJVM言語で、Javaのライブラリ資産をほぼそのまま利用できる
- Oderskyがjavac(Javaのコンパイラコマンド)の開発にも関わっていた経緯があり、Javaとの互換性を重視して設計されている
- 型推論やラムダ式などにより、Javaと比べて簡潔で読みやすいコードを書ける

[[currying]]のような関数型プログラミングの技法もサポートしている。

最新の動向は[[scala3|Scala 3]]を参照。
