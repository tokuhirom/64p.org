# Jasper

GitHubのissue/PRを読み・追跡するためのmacOS向けデスクトップアプリ。[jasperapp.io](https://jasperapp.io/)で配布されており、Apple Silicon Mac向けに提供されている。

## 機能

- **Stream** — GitHub検索クエリを条件にissue/PR一覧を作成し、通知を受け取れる(例: 自分が作成したissue、特定リポジトリのPRなど)
- 未読のissueコメント・レビューコメントのハイライト表示、ミニマップによる全体把握
- issue/PRのステータス・ラベル・マイルストーン・アサイン・レビュー状態を一覧確認
- GitHub Notifications・GitHub Projects(Kanban形式のプロジェクトボード)との同期連携
- キーボードのみでの操作に対応(ショートカットはカスタマイズ可能)

同名の「Jasper」を名乗るアプリは他にもAI文章生成・AI動画生成系のツールが複数あり、混同に注意。
