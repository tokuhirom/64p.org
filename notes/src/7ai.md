# 7AI

AIエージェントを使ってセキュリティ運用(SOC: Security Operations Center)業務を自動化する、米ボストン拠点のサイバーセキュリティ企業。「Seven AI」とも表記される。2025年2月にステルスから正式ローンチ。

## 概要

「Agentic Security Platform」を謳い、検知・調査・脅威ハンティングから(許可された範囲での)対応まで、セキュリティ運用のライフサイクル全体をAIエージェントが自律的に判断・実行する。人間のセキュリティチームを反復作業から解放し、より戦略的な業務にシフトさせることを狙う。

## 実績

ローンチから10か月で、エージェントが250万件超のアラートを処理し、65万件超のセキュリティ調査を完了。調査時間を数時間から数分に短縮し、本番環境で誤検知(false positive)を95〜99%削減したとしている。

## 資金調達・製品展開

2025年12月、Index Ventures主導で1億3000万ドルのシリーズA調達を発表。サイバーセキュリティ分野における史上最大のシリーズAラウンドと報じられている。直近では「7AI Federated SIEM」と「7AI Build」を発表し、AIネイティブなセキュリティ運用の基盤づくりを進めている。
