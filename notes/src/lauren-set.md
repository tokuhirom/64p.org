# ローレンセット

にじさんじ所属VTuber・ローレン・イロアスが一蘭で食べる際の注文スタイルを指す通称。一蘭の公式メニューには存在せず、店員に「ローレンセットで」と言っても通じない非公式な呼び名。

## 内容

よく語られる構成は以下の通り。

- 天然とんこつラーメン
- 秘伝の粉（辛さ）20倍級
- 替え玉2杯
- 白米複数杯
- 茹で卵複数個

かなりの大食い・激辛構成で、日常的な外食としてはヘビー級。

## 由来

配信の切り抜きやSNSでこの食べ方が拡散され、ファンの間で通称化した。挑戦を紹介する記事では、初心者向けに「辛さ3〜5倍・ご飯1杯程度」といった控えめな調整版も勧められている。
