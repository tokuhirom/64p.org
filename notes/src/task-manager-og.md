# Task Manager OG (TMOG)

Windows Task Managerの開発者Dave Plummer氏による、マルチOS対応のシステムモニタリングアプリケーション。2026年8月1日にmacOS版のBeta版が公開された。 #macos

## 開発者

Dave Plummer氏は1993年にMicrosoftのMS-DOSグループのインターンとして入社し、Windows開発に携わった。Windows Task Managerはもともと自宅で個人的に開発した外部プロジェクトだったが、Dave Cutler氏らの勧めで1995年に本体プロダクトに寄贈された。コード内には1995年11月10日の日付が刻まれている。Windows NTへのSpace Cadet Pinball移植にも関わっており、ソフトウェア特許を6件保有する。Microsoftを2003年に退社後、自身の会社SoftwareOnline LLCを設立。現在はテック系YouTubeチャンネル「Dave's Garage」を運営している。

## コンセプト

macOSのアクティビティモニタが持つ分かりやすさと、Windowsのタスクマネージャーが持つ情報の詳細さを両立させることを狙ったアプリ。Electron等のWeb UI技術に頼らないネイティブアプリとして実装されている。

## 画面構成

- **Summary** — 統合的な情報表示
- **Performance** — CPU、メモリ、ストレージ、ネットワーク、エネルギー消費、温度などを個別監視
- **Processes** — プロセス一覧表示

## 対応OS・提供形態

- 2026年8月1日時点ではmacOS版のBetaのみが無料で公開されている。配布元: [tmog.org](https://tmog.org/)
- Windows版・Linux版も開発中とされ、Windows版もElectron等ではなくネイティブアプリとして提供される予定。
- 無料版の提供を継続しつつ、将来的に有料のPro版をリリースする可能性が示されている。
