# ハッカソンでのコーディングエージェント向けスキル活用

ハッカソン運営において、参加者に以下の手順を踏んでもらうだけで、参加者全員が確実にCloudflareへデプロイできた、という知見。

1. スターター(テンプレート)にハッカソン用スキルを同梱しておく
2. 参加者側でCloudflare用スキル・Hono用スキルを追加インストールしてもらう
3. コーディングエージェントを起動する

## ポイント

ハッカソンで詰まりがちな「環境構築・デプロイ設定」のボトルネックを、エージェントに渡す知識(スキル)を主催者側で事前に用意しておくことで解消している。参加者は「何をどう書くか」ではなく「何を作るか」に集中でき、デプロイ手順の個人差・ハマりどころを吸収できる。onboarding時間が短いイベントとの相性が良い構造。
