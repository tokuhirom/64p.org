## 考えたこと

ハッカソンで詰まりがちな「環境構築・デプロイ設定」のボトルネックを、エージェントに渡す知識(スキル)を主催者側で事前に用意しておくことで解消している。参加者は「何をどう書くか」ではなく「何を作るか」に集中でき、デプロイ手順の個人差・ハマりどころを吸収できる。onboarding時間が短いイベントとの相性が良い構造だと思う。
