# macOSメニューバー常駐ユーティリティ

macOSの画面右上「メニューバー」に常駐し、軽量な単一機能を提供するタイプのユーティリティアプリ群。標準機能を補うためにサードパーティ製で存在することが多い。

#macos #moc

## 主なツール

- [[ice-menu-bar-manager|Ice]] — メニューバーアイテムの表示/非表示・並べ替えなど、メニューバー自体の見た目・レイアウトを管理する
- [[meetingbar|MeetingBar]] — カレンダーの現在・次の会議予定をメニューバーに表示し、ワンクリックで参加できる
- [[alttab|AltTab]] / [[ctab|cTab]] — 標準のCommand+Tabがアプリ単位の切り替えしかできないのに対し、ウィンドウ単位での切り替えを実現するウィンドウスイッチャー。メニューバーそのものを管理する[[ice-menu-bar-manager|Ice]]とは異なり、バックグラウンドに常駐してキー操作をフックする点が共通する

IceとMeetingBarは「メニューバーに何を表示するか」を扱うのに対し、AltTabとcTabは「メニューバーアイコンとしては目立たないが常駐して動作する」タイプという違いがある。
