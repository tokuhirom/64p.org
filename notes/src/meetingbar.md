# MeetingBar

カレンダーの現在・次の予定をmacOSのメニューバーに表示し、ワンクリックでオンライン会議に参加できるアプリ。[leits/MeetingBar](https://github.com/leits/MeetingBar)としてGitHubで公開されており、Swift 6製。Mac App Store・Homebrew(`brew install meetingbar`)・直接ダウンロードで入手でき、無料。

## 機能

- 現在・次の会議への参加リンクをメニューバーからワンクリックで開ける
- グローバルキーボードショートカットで直近の会議に即参加
- 任意の会議サービスでのアドホック会議作成
- Google Meet、Zoom、Microsoft Teams、Webex、Slack Huddle、FaceTimeなど50以上の会議サービスに対応
