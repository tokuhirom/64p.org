# セキュリティ運用

#security #moc

セキュリティインシデントの監視・検知・対応と、それを支えるツール・知識体系・攻撃側視点の検証手法についてのノートを束ねるハブノート。

## 防御側の組織と活動

- [[soc|SOC]] — 監視・検知・対応を専門に担う組織。Tier 1（トリアージ）〜Tier 3（脅威ハンティング）のティア構成
- [[threat-hunting|脅威ハンティング]] — アラートを待たず、既に潜んでいる脅威を仮説駆動で能動的に探す活動
- [[7ai|7AI]] — SOC業務（トリアージ・調査・ハンティング）をAIエージェントで自動化する企業の実例
- [[noc|NOC]] — 隣接概念。セキュリティ特化のSOCに対し、ネットワークの可用性・パフォーマンス維持を担う

## 検知・対応のツール

- [[siem|SIEM]] — 環境全体のログを集約・相関分析してアラートを上げる「広さ」担当の基盤
- [[edr|EDR]] — エンドポイントの挙動を記録・監視し隔離等の対応まで行う「深さ」担当のツール

## 知識体系・指標

- [[mitre-attack|MITRE ATT&CK]] — 攻撃者のTTPs（戦術・技術・手順）を体系化したナレッジベース。検知・ハンティングの共通語彙
- [[ioc-ioa|IOC/IOA]] — 検知の手がかりとなる指標。事後の侵害証拠（IOC）と進行中の攻撃兆候（IOA）

## 攻撃側視点での検証（オフェンシブセキュリティ）

- [[penetration-test|ペネトレーションテスト]] — 攻撃者と同じ手法で疑似攻撃し、防御の弱点を実証する手法
- [[metasploit|Metasploit]] — exploitの開発・実行を担う代表的なペンテストフレームワーク
- [[burp-suite|Burp Suite]] — Webアプリ診断の定番プロキシツール
- [[kali-linux|Kali Linux]] — ペンテストツールを同梱したLinuxディストリビューション（モバイル版は[[kali-nethunter|Kali NetHunter]]）
- [[hack-the-box|Hack The Box]] — 許可された仮想環境でペンテスト技術を練習できる学習プラットフォーム

## 脅威の実例

- [[ransomware|ランサムウェア]] — データ暗号化と身代金要求を組み合わせた代表的な脅威。国内被害は[[japan-ransomware-incidents|国内ランサムウェア被害事例]]（ハブノート）にまとめている

## 関連領域

- [[devsecops|DevSecOps]] — 運用段階ではなく開発パイプラインの側にセキュリティを組み込むアプローチ
