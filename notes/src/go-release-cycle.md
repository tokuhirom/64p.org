# Goのリリースサイクルとサポートポリシー

#golang

Goのメジャーリリース（1.24, 1.25, ...のようなX.Y）は**半年ごと**、毎年2月と8月に出る。

- Go 1.23.0: 2024-08-13
- Go 1.24.0: 2025-02-11
- Go 1.25.0: 2025-08-12
- Go 1.26.0: 2026-02-10

## サポートポリシー

各メジャーリリースは「その後に2つの新しいメジャーリリースが出るまで」サポートされる。つまり**常に新しい2つのメジャーリリースだけがサポート対象**で、サポート期間は実質1年。例えばGo 1.26が出た時点でGo 1.24はサポート終了になる。

サポート中のリリースには、クリティカルな問題（セキュリティ問題含む）の修正がマイナーリビジョン（1.26.1, 1.26.2, ...）として提供される。マイナーリビジョンはおおむね1〜2ヶ月ごとに出ている。

## 関連

- この「直近2バージョンのみサポート」という前提が、[[go-mod-go-directive|go.modのgo directive]]を1つ前のメジャーリリースに留めるべきという議論の背景になっている。

## [[go-tooling|Goの開発ツーリング]]の中での位置づけ

個別ツールの話ではなく、go directiveの設定方針や[[gopls]]のサポート範囲など、ツーリング全般の判断の背景となる大前提。
