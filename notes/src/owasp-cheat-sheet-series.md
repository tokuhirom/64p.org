# OWASP Cheat Sheet Series

[[owasp|OWASP]]が公開する、個別のアプリケーションセキュリティのトピックごとに「開発者が実際に実践できる」対策の実装指針を簡潔にまとめたドキュメント群。2024年3月時点で91個のチートシートが存在し、Flagship Project（OWASPの中でも成熟度・実用性が高いと認定されたプロジェクト）に位置づけられている。

[[owasp-top-10|OWASP Top 10]]や[[owasp-wstg|WSTG]]が「何が重大リスクか」「どうテストするか」を扱うのに対し、Cheat Sheet Seriesは「実際にどう直すか・どう実装するか」という対策側のリファレンスに徹している点が特徴。詳細で網羅的だが実践困難なベストプラクティス集ではなく、大多数の開発者が現実的に実装できる粒度の指針を志向している。

[[ssrf|SSRF]]にも[Server Side Request Forgery Prevention Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Server_Side_Request_Forgery_Prevention_Cheat_Sheet.html)があるように、[[owasp-top-10|OWASP Top 10]]・[[owasp-api-security-top-10|OWASP API Security Top 10]]に掲載される脆弱性カテゴリの多くに対応するチートシートが用意されている。
