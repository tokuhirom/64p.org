# マネーフォワード クラウドAIトークン管理

2026年8月17日にマネーフォワードが発表した、法人向けにAI利用コストを可視化する無料サービス。「クラウドAIトークン管理」が正式名称。

## 概要

ChatGPTやClaudeなどのAIツール・LLMモデルの利用量・コストをダッシュボードで一元管理できるサービス。API連携やCSV取り込みでデータを取得し、LLMモデルごと・ユーザーごとに利用量を可視化する。

## 主な機能

- **ダッシュボード可視化** — AIツール/LLMモデル別、ユーザー別に利用量を確認
- **期間比較機能** — コスト増加要因を特定しやすくする
- **カードコントロール機能** — 「マネーフォワード ビジネスカード」をAIツール決済専用カードとして活用し、カードごとに上限額・用途を指定して予算超過や用途外利用を未然に防ぐ（リアル・バーチャル複数枚発行対応）

## 料金・対象

マネーフォワード クラウドの既存ユーザーに限らず、マネーフォワードID（共通ID）を取得すれば無償で利用可能。
