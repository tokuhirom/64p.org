# 4価元素・14族元素

価電子(最外殻電子)を4個持つ元素のこと。「4価」と呼ぶ。 #chemistry #electronics

元素周期表では「14族元素」にあたる。炭素族元素、IV族元素(短周期表での旧称)、IVB族元素(CAS式)、IVA族元素(旧IUPAC式)など複数の呼び方がある。

[[carbon|炭素]]・[[silicon|シリコン]]・ゲルマニウムなどが該当する。

## 半導体との関わり

シリコン(Si)のような4価元素の結晶に、価電子数の異なる不純物をごく微量[[doping|添加(ドープ)]]することで半導体の性質が生まれる。

- 3価の不純物(ホウ素など)をドープ → [[p-type-semiconductor|P型半導体]]
- 5価の不純物(リンなど)をドープ → [[n-type-semiconductor|N型半導体]]

## [[semiconductor|半導体]]の中での位置づけ

シリコンなど代表的な半導体材料が属する元素グループ。価電子が4個であることが不純物ドープによる半導体化を可能にする、材料選定の出発点。
