# talks/

発表スライド置き場。各ディレクトリは presen5 (`talks/assets/presen5/`) で `main.txt` を表示する。

## 必須: 会場でネットワークなしで動くこと

会場の Wi-Fi は当てにならない。発表に使うものは、手元のチェックアウトをローカルの HTTP サーバ（例: `cd talks && python3 -m http.server`）で開けば、**ネットワーク接続なしで全部動く**状態にしておく。

- スライドから読み込む JS・CSS・画像・フォント・WebAssembly などは、すべてローカルのファイルを相対パスで参照する。CDN や外部 URL から読み込まない。
- 大きいファイル（wasm など）をリポジトリに入れたくない場合は、事前に取得するコマンドを用意してよい。ただしその手順を、その発表ディレクトリの `README.md` に必ず書く。取得後はネットワークなしで動くこと。
- 外部 URL へのリンク（クリックして開くもの）は書いてよいが、発表の流れがそれに依存しないようにする。
- 変更したら、外部への通信をすべて遮断したブラウザ（Playwright の `context.route` で localhost 以外を abort する等）で開き、デモを含めて動くことを確認する。

## 必須: 16:9 の PC とスマホで全部表示され、文字が小さすぎないこと

- 発表は 16:9 のプロジェクタ。スライドの文字は全部画面内に収まっていること（はみ出し・見切れ禁止）。
- 同じスライドをスマホでも問題なく見られること（あとで公開して見てもらうため）。
- 収めるために文字を小さくしすぎない。下限を決めて、それより小さくしないと収まらないスライドは分割する。
- Playwright で全スライドを検査するスクリプトを用意して確認する（例: `20261129-yapc-tokyo-mutsu/check-layout.js`）。
