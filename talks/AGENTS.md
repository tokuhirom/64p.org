# talks/

発表スライド置き場。各ディレクトリは presen5 (`talks/assets/presen5/`) で `main.txt` を表示する。

## 必須: チェックアウトしただけで、ネットワークなしで動くこと

会場の Wi-Fi は当てにならない。発表に使うものは、リポジトリをチェックアウトしてローカルの HTTP サーバ（例: `cd talks && python3 -m http.server`）で開けば、**ネットワーク接続なしで全部動く**状態にしておく。

- スライドから読み込む JS・CSS・画像・フォント・WebAssembly などは、すべてリポジトリ内のファイルを相対パスで参照する。CDN や外部 URL から読み込まない。
- 「発表前にスクリプトで取ってくる」も不可。チェックアウト直後にそのまま動くこと。
- 外部 URL へのリンク（クリックして開くもの）は書いてよいが、発表の流れがそれに依存しないようにする。
- 変更したら、外部への通信をすべて遮断したブラウザ（Playwright の `context.route` で localhost 以外を abort する等）で開き、デモを含めて動くことを確認する。
